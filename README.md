A Java-based ordering application designed to streamline the transaction process for a small restaurant or fast-food establishment. The program provides an intuitive graphical interface for cashiers to easily browse menu items, manage customer orders, and calculate totals, thereby improving service speed and order accuracy. 
Features:
Features a visual interface displaying categorized food and beverage items with their corresponding prices.
Allows users to add, remove, or modify item quantities before finalizing an order.
Automatically computes the order subtotal, applicable taxes (e.g., VAT), and the final total.
Generates a summary of daily sales and maintains a transaction history during the active session.
Scope:
Building a functional and user-friendly Graphical User Interface (GUI) using Java Swing.
Implementing core POS functionalities, including order creation, cart management, and digital receipt generation.
Managing a local, structured catalog of menu items and tracking session-based sales data.
Implementing Admin side for account management of the ordering system.
Limitations:
Limited to Cash Transactions only, no integrated credit card processing or digital wallet.
Data is stored locally and is not accessible via a web browser or remote server.
